📦 AI-Driven Inventory System

  Este projeto é um sistema de gestão de estoque e precificação automática, desenvolvido sob a metodologia de AI-Driven Development. Atuei como arquiteto de
  soluções, definindo a lógica de negócio, a estrutura de dados e orquestrando a IA para a implementação técnica.

  🚀 O Problema Resolvido

  O sistema resolve a dor de pequenos lojistas que precisam de:
  1. Precificação Ágil: Cálculo automático de margem de lucro (35%) sobre o preço de custo, com flexibilidade para ajuste manual.
  2. Controle de Fluxo: Atualização automática de saldo de estoque em cada operação de entrada ou saída.
  3. Visão Financeira: Relatórios de vendas por item e faturamento total em períodos customizados.

  🛠️ Stack Técnica

  - Linguagem: Python
  - Interface: Streamlit (Dashboard interativo)
  - Banco de Dados: SQLite (Persistência local)
  - Análise de Dados: Pandas

  🏗️ Arquitetura de Solução

  O software foi projetado seguindo a separação de responsabilidades:
  - app.py: Responsável pela camada de apresentação e interação com o usuário.
  - database.py: Responsável pela persistência, queries SQL e integridade dos dados.

  🤖 Processo de Desenvolvimento (AI Orchestration)

  Este projeto não foi apenas "codado", mas orquestrado via IA. O fluxo de trabalho consistiu em:
  1. Definição de Requisitos: Mapeamento de regras de negócio (Margem de 35%, fluxo de estoque, filtros de data).
  2. Design de Dados: Definição do esquema do banco de dados (Tabelas de Produtos e Transações).
  3. Iteração de Prompts: Comando de implementação modular para garantir que a interface e o banco estivessem desacoplados.
  4. QA (Quality Assurance): Testes de stress para validação de cálculos financeiros e consistência de saldo de estoque.
